# README 截图清单

把图片按下列文件名放到本目录后，到上级 `README.md` 里**取消对应 `<!-- ... -->` 注释**即可显示。

| 文件名 | 拍什么 | 优先级 |
| --- | --- | --- |
| `01-hero-workspace.png` | 主工作台：左编码 / 右谱面 | 必拍 |
| `02-live-preview.gif` | 打字 → 右侧出谱（3–6 秒循环） | 必拍 |
| `03-command-arrange.png` | 指令打谱：结构 / 和弦 / 节奏型 | 必拍 |
| `04-notation-styles.png` | 六线 / 简谱 / 五线（可拼图） | 必拍 |
| `05-playback.png` | 播放中的谱面 | 可选 |
| `06-chords-tuner.png` | 和弦查找或调音器 | 可选 |
| `07-gp-import.png` | GP 导入 | 可选 |
| `08-export.png` | 导出菜单 | 可选 |
| `09-cloud-scores.png` | 我的曲谱 | 可选 |
| `10-desktop-shell.png` | 桌面独立窗口 | 必拍 |
| `11-syntax-manual.png` | 语法表 / 手册 | 可选 |

## 拍摄注意

- 宽边约 1280–1600px；单张尽量 &lt; 500KB
- 全套同一主题色；用演示曲名，勿露真实账号 / 订单
- 编辑器里放 8–16 小节有和弦的弹唱 demo，比空模板好看
